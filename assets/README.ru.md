# Замороженная языковая модель

Файл `assets/model.bin` содержит данные о частотах и символьных моделях из
[`model/data/model.inc.gz`](../model/README.ru.md), перекодированные в индексы алфавита и знаковые
целые числа в микроединицах с порядком байтов little-endian. Все 396 107 значений с шестью знаками
после запятой сохраняются точно; модель не переобучается, не перекалибруется и не перенормируется.
Файл `model-provenance.json` связывает замороженные исходные данные, упаковщик, выходные байты и
число слов каждого языка. Команда `tools/pack-model.py --check` заново создаёт все файлы без
обращения к сети и сравнивает их побайтно.

> [!NOTE]
> Юридическую силу имеют английский текст `assets/README.md` и сами файлы уведомлений; настоящий
> перевод приводится для удобства.

Данные модели получены из wordfreq 3.1.1 и распространяются по лицензии CC-BY-SA-4.0. Файл
`model-notice.txt` и указанные в нём источники необходимо хранить вместе с производными данными и
двоичными файлами. Файл `wordfreq-code-license.txt` содержит отдельное уведомление, относящееся к
исходному коду wordfreq; на лицензию данных оно не влияет. Формат данных преобразован разработчиками
Keyrill. Исходный код приложения распространяется по лицензии MIT; это обстоятельство не меняет
лицензии данных модели и их первоисточников.
