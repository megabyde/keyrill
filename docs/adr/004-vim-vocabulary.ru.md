# ADR 004: чтение существующих файлов словарей Vim

> [!TIP]
> **Статус:** принято.

Личный словарь берётся из уже имеющихся у пользователя файлов Vim `.add` в кодировке UTF-8. Эти
файлы читаются на месте, только для чтения; при перезагрузке сохраняется последний удачный снимок.
Разбор выполняется по тем же правилам, что и в самом Vim: строка, первый байт которой равен `#`,
считается комментарием (команды Vim `zw`, `zug` и `zuw` перезаписывают этот байт, из-за чего за ним
может остаться невалидная последовательность UTF-8), а строка, которую Keyrill не может
использовать, пропускается и учитывается в счётчике, вместо того чтобы отвергать весь файл. Были
рассмотрены следующие альтернативы: собственный словарь приложения, синхронизация с удалённым
репозиторием, разбор двоичных файлов `.spl` и запуск Vim при каждом исправлении. Каждая из них
добавляет издержки, связанные с владением данными, лицензированием, приватностью или сопровождением,
без доказанной необходимости.

Различия между признанными, редкими и запрещёнными словами и правила регистра сохраняются. Наличие
слова в личном словаре защищает его, но не даёт кандидату частоты. Отсутствие файла никогда не
мешает набору и ручному преобразованию. Для автоматического исправления необходим источник для
каждого из двух языков; пустой файл является допустимым источником, как и отсутствующий файл по пути
по умолчанию, поскольку Vim создаёт этот файл лишь при первой команде `zg`. Путём по умолчанию
считается тот, по которому `zg` создаёт файл при пустом параметре `'spellfile'`:
`~/.vim/spell/{en,ru}.utf-8.add`, а в Windows — `~/vimfiles/spell`. Если файл отсутствует по пути,
выбранному пользователем, словарь этого языка считается отсутствующим. Сам Keyrill эти файлы никогда
не изменяет.

Списки слов, которым обучена проверка орфографии операционной системы, читаются так же — на месте и
только для чтения, так что слово, добавленное командой Learn Spelling в macOS или Add to dictionary
в Windows, защищено без ведения второго списка. Эти списки представляют собой простые перечни слов,
а не синтаксис Vim, и никогда не являются обязательными: исправление ждёт готовности только двух
источников Vim. Исключённые слова Windows считаются запрещёнными, как и слова, отмеченные командой
`zw` в Vim.

Решение следует пересмотреть, если изменится способ, которым пользователь ведёт свой словарь, или
если нужную семантику не удастся выразить в этом формате.
