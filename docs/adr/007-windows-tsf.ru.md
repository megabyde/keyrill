# ADR 007: Windows Text Services Framework

> [!WARNING]
> **Статус:** предложено; требуется подтверждение во время выполнения.

Основным вариантом для Windows является нативная текстовая служба TSF: сеансы редактирования,
которые выдаёт система, явные контексты и собственные композиции соответствуют
[архитектуре](../../ARCHITECTURE.ru.md) лучше, чем чтение через UI Automation с синтетической
заменой. Предпочтительно использовать `windows-rs` поверх общего ядра; допустима и тонкая нативная
прослойка.

Согласно документации Microsoft, результат запроса и результат самого сеанса редактирования
возвращаются раздельно, а владелец может отклонить создание композиции, вернув при этом успех и
нулевой указатель на композицию. Эталонный пример Microsoft не обрабатывает правильно ни то, ни
другое. Блокировки не обеспечивают ни отката, ни сохранения фокуса, а сбой библиотеки, загруженной в
процесс редактора, может привести к аварийному завершению этого редактора.

Принять решение окончательно можно будет после физических тестов в нативном редакторе, которые с
доказательствами на всём документе покажут исправление, продолжение набора, смену фокуса, отмену и
отказ в сеансе. Решение следует сузить или отвергнуть, если эта семантика или обычный набор EN/RU
окажутся непрактичными. Успешная сборка в CI этого статуса не меняет. Исходный контракт описан в
разделе о [переносе на другие платформы](../porting.ru.md#windows-text-services-framework).
