# Rust API

Здесь собрана документация rustdoc для двух библиотечных крейтов, построенная из того же коммита,
что и настоящий сайт. Документация написана на английском языке.

- [keyrill_core](../api/keyrill_core/index.html): переносимый движок, не содержащий небезопасного
  кода
- [keyrill_ffi](../api/keyrill_ffi/index.html): версионированный интерфейс C ABI, к которому
  обращаются нативные адаптеры
